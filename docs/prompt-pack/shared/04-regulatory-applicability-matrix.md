# Colombian Regulatory Applicability Matrix

**Research date: 2026-11-08 (America/Bogota). Verification pass v1.1 on the same date.** This is an engineering input, **not legal advice**.
Rows marked `LEGAL-REVIEW` must still be signed off by a Colombian tax/labor/data-protection professional before go-live (EG-7). This applies even to values read from official text, because interpretation (combinations, bases, exceptions) is the reviewer's job.

Status legend (exact meaning, see shared/05 for the access method of each source):
* `VERIFIED-PRIMARY`: an official or official-compilation text was **opened and read** on 2026-11-08, and the cited content was found in it. Official copies used: DIAN normograma, Rama Judicial SIDN (scans of the Diario Oficial), Corte Constitucional relatoría, and the normative compilations of public entities (CRA, Colpensiones).
* `VERIFIED-SEARCH`: the content was seen only as a search-engine extract of an official page. The page itself could not be opened from the research box.
* `VERIFIED-SECONDARY`: only non-official commentary confirms it.
* `UNKNOWN`: not determinable today. The system **fails closed** for the affected dates or entities.
* `DISPUTED`: the official value exists, but it has a litigation or suspension history. It computes with a warning and a snapshot (C1-9).

Implementation rule (C1-9): every value is a **dated parameter** in `tax.parameters` (P06) with `valid_from`, `valid_to`, `source_id`, `status`, and `legal_reviewed_by/at`. 2026 seeds are provided; 2027+ annual values fail closed.
