## What was built
Shared harness package `tests/cross_module/qa_harness/` (stdlib + PyYAML; Django imported lazily):

| Module | Purpose |
|---|---|
| `openapi.py` | Index of all **1,221** contract operations: method/path/permission/owner, read channel (list, detail, export, report, AI, portal, write), money/stock effect, response/request field classifications (incl. `allOf` pages, nested dotted names; exports borrow the resource read model), 65 webhooks. |
| `principals.py` | Principal matrix **2 tenants × 3 companies × 7 kinds** (admin, salesperson own-customers, warehouse-scoped, payroll, auditor, AI delegated, MCP limited-scopes) = 14 principals with deterministic synthetic UUIDs; permissions evaluated from the frozen role templates (fnmatch, deny wins; AI = user ∩ delegation ceiling − template denies; MCP = user ∩ scopes; classification ceilings). Builds valid `kernel.tenancy.TenantContext`s. |
| `oracle.py`, `datasets.py` | Expected policy independent of the system under test: `can_see` (tenant, company, owner, warehouse), forbidden fields (above the ceiling, `secret` always), expected statuses (401/403 anonymous; 403 BFLA; 404 (403 tolerated) BOLA; 200 own). Synthetic datasets spread over both sides of every boundary. |
| `leak.py`, `transports.py` | Invariant-12 framework: `generate_cases` (anonymous, visibility, own object, BOLA foreign tenant, BOLA out-of-scope, BFLA; never executes allowed writes), `LeakSuite` + checker (rows ⊆ policy, unknown rows, foreign tenant/company ids, masked fields absent, error bodies must not echo protected data), CSV matrix + summary. Transports: Django test client (pluggable authenticator) and loopback-only HTTP. Unrouted operations → `NOT_IMPLEMENTED`, no authenticator → `BLOCKED` (never counted as PASSED). |
| `failure_injection.py` | `fail_after(n)` (Django `execute_wrapper`, raises before the n-th non-control SQL statement), `AtomicityProbe` (row count + order-independent md5 digest per table), `sweep()` = all-or-nothing check with injection at every statement (or a reproducible sample). The engine for T-P22-FIN-01/STK-01. |
| `routes.py` | Contract runner: implemented Django routes ↔ contract paths (UR-22). |
| `ledger_dump.py` | Scenario ledger CSV for the contador (EG-8) + Decimal-only invariant-1 check per currency and functional currency. |
| `traceability.py` | `docs/traceability.csv` from `@pytest.mark.req("UR-xx")` (function/class/module), Playwright `@UR-xx` titles and JUnit/Playwright JSON outcomes; `--check [--gate G2]` fails on uncovered URs. |
| `evidence.py` | Gate evidence collector → `docs/gates/G<N>-evidence/<label>/` with `index.json` (sha256, JUnit totals, commit); refuses secret-like content. |
| `defects.py` | Registry of P22 defects → `xfail(strict=True, reason="DEF-…")`. |

Suites:
* `tests/cross_module/test_xm_*` — harness self-tests (index, principals, failure injection on the real kernel UoW + a non-atomic
  mutant, ledger dump, traceability, evidence, e2e config statics).
* `tests/security/` — leak framework **mutation tests** against an in-memory reference API (`reference_api.py`): correct
  reference passes every case; each of 8 mutants (no auth, no BFLA check, no tenant/company/owner/warehouse filter, no field mask,
  error-body echo) is caught; uniform-403 control is not flagged. Live suites on the real URLconf: generated leak matrix over all
  non-portal operations (`reports/leak/`), anonymous refusal on every implemented route × 4 methods, route conformance,
  configuration baseline (DEBUG, hosts, CSRF origins, CORS, AllowAny, security headers, environment endpoint without secrets,
  problem+json errors).
* `tests/perf/` — stdlib closed-loop load generator (`loadgen.py`, integer-ns latencies, nearest-rank p50/p95/p99), budgets from
  P22 §9 (`budgets.json`), real loopback run against the Django WSGI app (`reports/perf/`).
* `tests/e2e/` — Playwright config (system Chrome, loopback-only, es-CO, America/Bogota, reduced motion, traces on failure,
  JSON/JUnit reports), fixtures (frozen clock, DEV banner, axe a11y), COP formatter, `harness-selftest.mjs`, visual README.

## How to use
```bash
uv run --frozen pytest tests/cross_module tests/security tests/perf -q        # ~3 s, real PostgreSQL (make db-setup)
make test-ids IDS="p22a"                                                     # same via the standard target
python3 tests/cross_module/qa_harness/traceability.py [--check --gate G2]
python3 tests/cross_module/qa_harness/evidence.py --gate G2 --label <label>
python3 tests/perf/loadgen.py --base http://127.0.0.1:8080 --path /api/health/live --users 20 --requests 50
node tests/e2e/harness-selftest.mjs                                          # system Chrome, no app needed
```
Writing a leak test for a new module (P22c, module owners): seed rows with `datasets.seed_resource`, pass an authenticator to
`DjangoClientTransport`, `generate_cases(openapi.select(module="sales"), matrix(), ds)`, run `LeakSuite`, assert `summarize()["failed"] == []`.
Failure injection for a posting service: `sweep(lambda: service(...), AtomicityProbe([...tables]), expect_changed=[doc, journal, subledger, outbox], reset=...)`.

## Decisions taken under ambiguity
1. Harness lives in `tests/cross_module/qa_harness/` (owned path); other suites add it to `sys.path` in their conftest; test files
   use unique prefixes (`test_xm_`, `test_sec_`, `test_perf_`) because `tests/` has no packages.
2. Money/stock targets: contract tags win; until P02 adds them, a shared/07-derived list labelled `derived-shared07` (CCR P22a-1).
3. Anonymous refusal accepts 401/403/404/405 (never 2xx); the exact 401 contract is a separate strict-xfail test (DEF-P22-002).
   Hidden objects: 404 preferred, uniform 403 tolerated (no existence oracle either way), 2xx always a leak.
4. The leak suite never executes allowed writes (no state change); positive write behaviour belongs to module tests and P22b scenarios.
5. Portal operations (46) are excluded from the internal matrix: they are party-scoped by token (D-033) and need external
   identities (P22c/P22d). MCP has no REST surface (P02 decision 6): MCP/AI are covered by principals now and by transports later.
6. Search is not a separate REST channel in the contract (lists take `q`); search cases run as list visibility cases.
7. k6/Locust are not reachable from the cloud allowlist → stdlib load generator with integer-ns timing; pytest-django's
   `live_server` crashes without `STATIC_URL`, so the perf smoke uses a loopback wsgiref server (CCR P22a-5 §3).
8. The live leak CSV omits `NOT_IMPLEMENTED` rows (counted in the summary) to keep evidence small.
