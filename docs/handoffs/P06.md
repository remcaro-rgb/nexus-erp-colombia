Decisions taken under ambiguity (with rationale):
* Parameters are **tenant-scoped** rows seeded per tenant (no cross-tenant global writes); `company_id` NULL = tenant-wide.
* Statutory rates (VAT 19/5 %, ReteIVA 15 %, contributions) are open-ended from 2026-01-01 (store starts in 2026);
  annual values (UVT, SMMLV, transport allowance) end 2026-12-31 so 2027 fails closed.
* Two-person rule = proposer + a different approver; the approver may also record the EG-7 stamp
  (`parameters.legal_review=true`). Approval closes the previous open range or supersedes fully covered rows.
* Percent/per-mil values are stored in their units ("19") and returned as fractions (0.19) by the provider.
* Who withholds = the buyer (payer); sales documents (`FV`, `RC`, …) use company = seller, others company = buyer.
  Unknown parties get the most conservative profile (no agent flags, not VAT-responsible).
* Minimum withholding bases are compared with the document total per concept; at exactly the base the withholding applies.
* Rounding: COP 2 decimals ROUND_HALF_UP; LINE mode default; DOCUMENT mode returns `rounding_adjustment` for the
  ROUNDING line with a 1.00 tolerance; withholding totals are always Σ rounded lines.
* Values from opened official text but with litigation (Decreto 572) stay DISPUTED; values not opened stay UNKNOWN
  rather than being filled from memory. Demo values live only in the `syn.`-prefixed synthetic fixture.
* `kernel.parameters.enforce` bug (CCR P06-2) is worked around in `tax.parameters.store.enforce`.
