## Extension points for P09b / P09c (no edit of P09a files needed)
* **Models:** put them in `backend/inventory/<part>/models.py` (`part` ∈ issues, barcodes, bom, transformations); the core
  `inventory/models.py` imports them, so they register under the `inventory` app label.
* **Migrations:** put files in `backend/inventory/<part>/migrations/` named `01xx_<part>_*.py` with
  `dependencies = [("inventory", "0002_db_guards")]` (or the latest core migration); `inventory/migrations/__init__.py`
  appends those directories to the package path so Django loads them. Write them by hand (or move what `makemigrations`
  generates) and enable RLS with `iam.rls.enable_sql` + `kernel.db.company_fk_sql` like 0002.
* **URLs:** `backend/inventory/<part>/urls.py` with `urlpatterns` is included at `/api/v1/inventory/` automatically.
* **Stock/valuation:** call `services.get(Inventory)` (or `inventory.stock.service.SERVICE` for `internal_move`, `repack`,
  `detailed_availability`) inside your UoW; post GL yourself with `PostingService` (issues: Dr concept expense / Cr INVENTORY
  with `result.total_value`; returns via `return_moves` restore the original cost/bin/lot). Errors: `stock_insufficient`,
  `location_not_leaf`, `lot_required`, `uom_precision_violation`, `reservation_conflict`.
* **Frontend pages:** export them from your folder and add them via a separate descriptor contribution, or a CCR to add keys
  to `features/inventory/module.ts` (`movimientos/salidas`, `maestros/codigos-etiquetas`, `produccion/*`).

## Decisions taken under ambiguity
* D1 Valuation scope is company-wide (ADR-008 default); `Warehouse.valuation_scope` exists but only `COMPANY` is honoured.
* D2 Transfers post GL (F-INV-REQ posting text, higher precedence than shared/07 §3 "none"): Dr/Cr between INVENTORY and
  INVENTORY_IN_TRANSIT at the current average cost; valuation is unchanged. In-transit bin = TRANSITO of the source warehouse.
* D3 Receipts/issues through `StockService` do **not** post GL themselves; the calling document (purchasing receipt, sales
  delivery, P09b issue) posts with the returned value in the same UoW (P09 prompt: "returns … posting lines that the caller
  passes into the same PostingService.post()"). `StockMoveResult.journal_entry_id` is therefore `None`.
* D4 Quality hold = an ACTIVE reservation with source `inventory.quality_hold` on the received bin (not available; released
  with `release`).
* D5 Same-warehouse bin-to-bin: no journal entry, valuation untouched; the move records `unit_cost` = average, `value` = 0.
* D6 Lot-tracked issues without a lot and without a bin use FEFO (lot expiry, then bin path); naming a bin without a lot →
  `lot_required`.
* D7 Negative stock: refused by default (D-032) in service and DB trigger; `allow_negative` warehouses skip the check and
  value the deficit at the average cost (the negative-stock correction posting of ADR-008 is not implemented — limit below).
