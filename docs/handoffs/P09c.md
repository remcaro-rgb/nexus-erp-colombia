## Decisions (non-obvious)
* D1 Normal waste is absorbed into outputs; abnormal waste (flagged, or the excess over template waste % + tolerance) is
  expensed to `SCRAP_EXPENSE` at input average cost (D-015).
* D2 Allocation basis: explicit cost shares (must total 100) → standard value → quantity. Non-main outputs are rounded
  half-up to 4 decimals; the main output takes the remainder, so documents balance exactly.
* D3 Stock-service idempotency is per (source, kind): one `issue` and one `receive` call per document.
* D4 Approval is required for yields outside tolerance (PORTIONING), deviation from planned qty (PRODUCTION) and MANUAL
  documents above 1,000,000 COP (module constant `MANUAL_APPROVAL_THRESHOLD`). Posting an unapproved order answers
  `transformation_yield_out_of_tolerance` (or `approval_required` for MANUAL).
* D5 Mass balance is enforced for PORTIONING and for MANUAL when every line shares one UoM; otherwise only value.
* D6 Production explosion inside an order is single-level (sub-assemblies are consumed as stocked items).

## Limits
* The manual approval threshold is a constant, not a per-company setting. No PDF print of transformation documents.
* Presentation repack moves packages through `SERVICE.repack`, which writes no `StockMove` (base quantity unchanged).
* Reversal of outputs uses the current average cost (stock-service rule); the variance is posted, not hidden.
