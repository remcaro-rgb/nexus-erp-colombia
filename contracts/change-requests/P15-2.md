# CCR P15-2 — notifications to external recipients (buyer e-mail with the AttachedDocument ZIP) (to P07)

Status: OPEN (P15, wave 3).

`kernel.interfaces.notifications.NotificationRequest` addresses an internal `recipient_id` (user UUID). Electronic-invoice
delivery goes to the **buyer's e-mail** (an external party) with a ZIP attachment (AttachedDocument XML + PDF from P17).

## Request
Add to the NotificationService contract an external-recipient variant, e.g. `ExternalEmailRequest(company_id, to_address,
template_code, data, attachments=[FileRef])`, enqueued in the caller's UoW and delivered by the P07 worker to the local capture
(Mailpit) in DEV, with bounce callbacks.

## Meanwhile (P15)
`einvoice.service.queue_delivery` builds the AttachedDocument, zips it, stores it as encrypted evidence and appends a
`DeliveryLog` row `QUEUED` with the masked recipient; `record_bounce` appends `BOUNCED` rows; `:resend-email` re-queues. No e-mail
is sent by P15 itself.
