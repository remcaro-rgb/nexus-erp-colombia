# CCR P17a-3 — semantic models contributed by modules, role sharing of saved reports, operations route, events

* From: P17a · To: P04 (iam), P01 (kernel operations), P02 (contracts), module owners · Type: integration note · Status: OPEN
* **Semantic models (ADR-009).** P17a merged `backend/reporting/semantic/models/{ledger,treasury,payroll}.yaml`. Other
  modules (sales, purchasing, inventory, pos, assets, crm…) send their `<module>.yaml` by CCR (format documented in
  `reporting/semantic/registry.py`: table, alias, `orm_model` + `policy_action` for the row scope, `resource_type` for
  the field mask, declared joins, typed + classified fields, measures, default filters, optional `k_anonymity`).
* **Role sharing.** Saved reports store `definition.share_roles`; P04's `TenantContext` carries no roles, so a published
  report is visible to every principal with `reporting.report.read` in the company row scope. Request: a
  `PolicyService` helper (or resource attribute) to test role membership so P17 can narrow visibility to the roles.
* **Operations.** `POST /api/v1/documents/render:render-batch` answers 202 with an `Operation` (rendered in the same
  request, status SUCCEEDED/FAILED) and `Location: /api/v1/operations/{id}`; the kernel `/api/v1/operations/{id}` route
  of `root.yaml` is not implemented yet (P01). Generated documents are referenced as `urn:nexus:documents.document:<id>`
  until a download route exists (request to P02: `GET /api/v1/documents/generated/{id}` in `documents.yaml`).
* **Events.** `contracts/events/documents/` has no event yet (adding one needs `contracts/events/catalog.yaml`, which
  P17a does not own). Request to P02: `documents.document.generated.v1` `{document_id, template_code, sha256,
  source_type, source_id}`.
* **Permission added (appended to the catalog):** `reporting.report.admin` (manage other users' saved reports).
