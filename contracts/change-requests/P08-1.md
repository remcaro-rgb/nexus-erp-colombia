# CCR P08-1 — UI endpoints consumed by the shell that are missing from the generated OpenAPI bundle

* **From:** P08 (UX shell / design system) · **To:** P02 (contracts), with P01 (`/ui/context`), P04 (IAM / portal), P07 (notifications, formulas), P18 (exports)
* **Status:** OPEN · **Wave:** 02 · **Blocking for P08:** no (the shell codes against the shapes below and renders honest
  `not_available` / error states when an endpoint answers 404/501).

## Context
`docs/spec/ui/module-registry.json › api` (frozen at G0) names the UI endpoints, and UI-CONTRACT §10 G0 says the P02 OpenAPI
"contains every endpoint in module-registry.json › api". The generated bundle `contracts/openapi/openapi.yaml` at main
`75ca9ca` does **not** contain these paths. The frontend types live in `frontend/src/lib/api/types.ts`.

| Endpoint (registry) | In OpenAPI? | Shape P08 consumes |
|---|---|---|
| `GET /api/v1/ui/context` | no (implemented by P01 in `backend/kernel/views.py`) | add `companies[] {id, legal_name, nit, code}` (only permitted), `periods[] {id,start,end,status,label}`, `roles[]`, `permissions[]`, `user {display_name}`, `session_idle_minutes`, `logout_url` (OIDC end-session URL). P01 currently returns `company_ids` only; the shell falls back to ids. |
| `GET /api/v1/ui/modules?company_id=` | no | `{groups[], modules[]}` = registry modules filtered server-side by permission (absent, not disabled). **Fail-closed:** without it the shell shows the context error screen. |
| `GET /api/v1/kpis/{module}` · `…/panels/{panel}` | no | `KpiResponse` / `PanelResponse {state, series[], points[{label, values{}}], items[]}` (decimal strings). |
| `GET /api/v1/search?q=&company_id=&limit=` | no | `{results[{id,type,title,subtitle,href}]}`, `type ∈ documentos|terceros|productos|cuentas|empleados`. |
| `GET /api/v1/notifications` / `POST /api/v1/notifications/read` | partially: `/api/v1/workflow/notifications` + `{id}:mark-read` exist | shell uses the existing P07 paths; please add a bulk `:mark-all-read` action (today: one call per item). |
| `POST /api/v1/exports` | `/api/v1/dataio/exports` exists | shell posts `{entity, params, company_id, period_id}` to `/api/v1/dataio/exports`; confirm the body schema. |
| `GET /api/portal/v1/kpis?portal=` | no | party-scoped `KpiResponse` for `portals[].dashboard.kpis` (P10/P11/P13 providers). |
| `GET /api/portal/v1/notifications` | no | `Page<NotificationItem>` scoped by the token's party. |
| `POST /api/v1/workflow/formulas:validate|:simulate` | yes (generic `ActionRequest/ActionResult`) | please pin the body: `params {expression, input_schema, inputs}`; result `{errors[{code,message,start,end}]}` / `{value, explain[{expression,value}]}`; on 422 `problem.errors[].pointer = "/expression/<start>-<end>"`. Adapter: `frontend/src/design-system/formula-editor/apiService.ts`. |
| `GET /api/health/ready` | no (anonymous, P01) | `{status: "ok"|…}`; sidebar "Estado del sistema". |

## Requested change
Add the paths above to `contracts/src` (P02 additive), with `x-permission` per the registry, then regenerate. No
breaking change for existing paths.
