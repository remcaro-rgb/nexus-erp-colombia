# CCR P22a-4 / DEF-P22-003 — OpenAPI schema endpoint is anonymous (P01)

* From: P22a · To: P01 (settings/urls) · Status: OPEN · Defect: DEF-P22-003 (strict xfail in `tests/security/test_sec_anonymous.py`)
* Observed: `GET /api/v1/schema` without credentials → 200 with the generated schema. drf-spectacular's `SERVE_PERMISSIONS`
  defaults to `AllowAny`, which overrides the DRF default `IsAuthenticated`.
* D-ALL 1 / D-P01: only `/api/health/live`, `/api/health/ready` and `/api/v1/system/environment` may be anonymous; no `AllowAny`.
* Request: `SPECTACULAR_SETTINGS["SERVE_PERMISSIONS"] = ["rest_framework.permissions.IsAuthenticated"]` (or remove the route
  and serve the frozen contract instead). The published contract is `contracts/openapi/openapi.json`.
