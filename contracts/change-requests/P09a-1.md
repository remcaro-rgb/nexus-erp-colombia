# CCR P09a-1 — inventory contract clarifications found while implementing the core (non-breaking for consumers)

Owner of the change: P02 (contracts/src/modules/inventory.yaml, contracts/errors.yaml) and P01 (kernel.interfaces.stock docstring).
Status: PROPOSED. P09a implements the stricter side of each point today; nothing in another task's path was edited.

1. **`Warehouse.branch_id` is required.** The contract source marks it `ref internal null`; F-ACC-BRANCH (T-ACC-BRANCH-03)
   and DIMENSIONS/FEATURES addenda require a same-company branch. Implementation: NOT NULL + composite FK
   `(tenant_id, company_id, branch_id) → iam_branch`; API answers `validation_failed` (missing) or `branch_cross_company`.
   Proposed: `branch_id: ref internal req` in `WarehouseInput`.
2. **Stock error code.** `kernel/interfaces/stock.py` docstring and `kernel.testing.fakes.FakeInventory` say
   `insufficient_stock`; `contracts/errors.yaml` registers only `stock_insufficient` (and says so). The real service and
   `inventory.testing.fakes.FakeInventoryService` use `stock_insufficient` (HTTP 422). Proposed: P01 aligns the docstring/fake.
3. **Cycle on location move.** No dedicated code exists; the API answers `validation_failed` with `reason: location_cycle`
   (pointer `/parent_id`). Proposed (optional): register `location_cycle` (422).
4. **Transfer state errors.** An action not allowed in the current state answers 409 `invalid_state_transition` (kernel
   Conflict code); approval by the requester answers 409 `sod_violation`. Proposed: list both in the transfer operations'
   `x-error-codes`.
5. **Additional response fields** (additive): `Warehouse.root_location_id|transit_location_id|valuation_scope`,
   `StockMove.kind|warehouse_id|presentation_id|qty_packages|unit_cost|journal_entry_id`, `Quant.available|warehouse_id`,
   `Transfer.ship_entry_id|receive_entry_id|shipped_at|received_at`, availability rows (`location_code`, `location_type`,
   `packaged_base`, `loose`, `packaged[]`). Cost/value fields are `confidential`.
6. **GL roles used by transfers:** `INVENTORY` and `INVENTORY_IN_TRANSIT` (account determination by `warehouse_id`).
   Proposed: P05/P21 add `INVENTORY_IN_TRANSIT` to the standard role list and the synthetic PUC seed.
