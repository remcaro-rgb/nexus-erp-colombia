# CCR P14-6 — `kernel.parameters.enforce` overwrites the error code (P01)

* From: P14 · To: P01 · Type: bug · Status: OPEN
* `enforce()` raises `ParameterUnknown(..., code=code)` / `ParameterNotVerified(..., code=code)` with the **parameter**
  code; `DomainError.__init__` treats `code=` as the error code, so the problem+json `code` becomes e.g.
  `assets.fiscal.max_annual_rate.computo` instead of `parameter_unknown` (HTTP status stays 422).
* Request: pass the parameter code as extra data (e.g. `parameter=code`) so `code` stays `parameter_unknown` /
  `parameter_not_verified`. P14's test asserts the exception class until then.
