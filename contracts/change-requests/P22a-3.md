# CCR P22a-3 / DEF-P22-002 — anonymous requests must get 401 + WWW-Authenticate (P04)

* From: P22a · To: P04 (IAM) · Status: OPEN · Defect: DEF-P22-002 (strict xfail in `tests/security/test_sec_anonymous.py`)
* Observed on `main`: `GET /api/v1/ui/context` without credentials → `403 application/problem+json` (`permission_denied`),
  no `WWW-Authenticate`. Cause: `REST_FRAMEWORK.DEFAULT_AUTHENTICATION_CLASSES = []` (P01 left authentication to P04).
* Contract: every protected operation declares `401 Unauthorized` (problem+json) and the OAuth2/bearer schemes; RFC 6750 requires
  `WWW-Authenticate: Bearer`. D-P20: anonymous `/mcp` → 401 with `WWW-Authenticate`.
* Request: P04's authentication classes answer anonymous calls with 401 + `WWW-Authenticate: Bearer realm="erp-dev"`; denied
  authenticated calls keep 403/404.
