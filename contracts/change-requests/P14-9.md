# CCR P14-9 — module-level UI permission codes of `activos` (P04 / P08)

* From: P14 · To: P04 (IAM `/iam/me` permission set), P08 (shell) · Type: integration · Status: OPEN
* `docs/spec/ui/module-registry.json` uses module-level codes for `activos`: `assets.read` (module, Resumen, Registro,
  KPIs), `assets.depreciate` (Depreciación, KPI sin_depreciar), `assets.write` (Bajas y traslados, quick action).
  They do not follow the catalog grammar `<module>.<resource>.<action>`, so P14 did not append them to the catalog.
* The API checks the catalog codes: `assets.asset.*`, `assets.depreciation_run.*`, `assets.asset_register.read`, … .
  Request: derive the module-level codes in `/iam/me` (e.g. `assets.read` ⇐ any `assets.*.read`;
  `assets.depreciate` ⇐ `assets.depreciation_run.post`; `assets.write` ⇐ `assets.asset.create|update|void`), as for the
  other modules' registry codes.
