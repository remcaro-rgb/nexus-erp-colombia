# CCR P11b-3 — bank account, contacts and tax data in the vendor master (P11a)

* From: P11b · To: P11a · Type: data model · Status: OPEN
* Need: F-PORTAL-SUP changes "the vendor master" (bank account, contacts, tax data) only after internal approval
  (bank: two approvers). `purchasing_supplier` has no such columns.
* Request: add `bank_account_enc` (encrypted at rest), `bank_account_last4`, `contacts`, `tax_data` to `Supplier`, or adopt
  `purchasing_supplier_master_data` (P11b) as the official extension, and expose a read for payments (P16).
* Meanwhile (P11b): `purchasing.portal.models.SupplierMasterData` holds the approved values (one row per supplier), written
  only by `decide_profile_change` when the required approvals are met; `bank_account_of()` returns the clear number to
  holders of `purchasing.supplier.update` (payment files). Encryption: `purchasing.portal.crypto` (same construction as
  `hr.crypto`; CCR P13a-3 proposes one shared kernel helper).
