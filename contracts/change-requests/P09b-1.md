# CCR P09b-1 — wire P09b pages and the Labels service into the inventory core (to P09a / integrator)

Status: OPEN (P09b, wave 04). Both files below are owned by P09a; P09b did not edit them.

## 1. Frontend page keys in `frontend/src/features/inventory/module.ts`
The shell discovers pages only through `features/*/module.ts`. Please add (lazy imports from P09b's folders):

```ts
"movimientos/salidas": lazy(() => import("./issues/IssuesPage")),
"maestros/conceptos-salida": lazy(() => import("./issues/IssueConceptsPage")),
"maestros/codigos-etiquetas": lazy(() => import("./barcodes/BarcodesPage")),
```
Keys follow `docs/spec/ui/module-registry.json › modules[id=inventario]`; if the registry uses different slugs, keep the
registry's and point them at the same components.

## 2. `Labels` service registration in `backend/inventory/registry.py`
`inventory.barcodes.labels.SERVICE` implements `kernel.interfaces.labels.Labels`. Please add it to `implementations()`:

```python
from inventory.barcodes.labels import SERVICE as LABELS
return {Inventory: SERVICE, StockService: SERVICE, Labels: LABELS}
```
Until then the P09b API calls the module directly; only other modules that resolve `services.get(Labels)` are affected.
