   * `dr-drill: ; scripts/ci/dr-drill.sh` (P03 deliverable 6, `make dr-drill`).
   * `devops-test: ; scripts/ci/run-tests.sh` (P03 tests T-P03-01..06, needs Docker, ~15 s, JUnit `reports/junit/p03-devops.xml`).
     Optional: call it from `make ci` when `docker info` succeeds.

2. **Dependencies** in `uv.lock` for the containers: `gunicorn`, `uvicorn-worker` (or `uvicorn`), `celery[redis]`,
   `psycopg[binary]` (or `psycopg[c]`). Without gunicorn/uvicorn the api image falls back to the Django dev server and logs
   a warning; without celery no `worker` container is started.
3. **Settings from env** (D-P01) — names provided by compose (`deploy/README.md` § Environment variables): `ERP_DB_HOST/PORT/NAME/USER/PASSWORD`,
   `ERP_SECRET_KEY`, `ERP_CACHE_URL`, `ERP_CELERY_BROKER_URL`, `ERP_OIDC_ISSUER`, `ERP_PUBLIC_ORIGIN`, `ERP_S3_*`, `ERP_EMAIL_*`,
   `ERP_*_MODE` adapters, `ERP_FIELD_ENCRYPTION_KEY`, `ERP_VERSION`. Celery app importable as `erp` (`erp/celery.py` + `app`), ASGI app `erp.asgi:application`.
4. **Endpoints** `/api/health/live`, `/api/health/ready`, `/api/v1/system/environment` (api healthcheck and `make dev-health` use them).
5. **Management command `outbox_relay`** (any app, `management/commands/outbox_relay.py`): `make dev-up` starts the
   `outbox-relay` container once it exists.
6. **Logging scrub filter**: the backend JSON log filter should load `deploy/observability/pii-patterns.json` (single source,
   also used by the OTel Collector) so T-P03-04 holds at both layers; logs carry `trace_id`, `tenant_id`, `company_id`.
7. **RLS binding detail found by T-P03-02**: after a `SET LOCAL app.tenant_id` transaction commits, the same (pooled) session
   returns `''` (not NULL) from `current_setting('app.tenant_id', true)`; a policy written as `...::uuid` then raises
   `invalid input syntax for type uuid`. Policies should use `NULLIF(current_setting('app.tenant_id', true), '')::uuid`
   (and the same for `app.company_ids`) so an unbound session sees zero rows instead of erroring.
