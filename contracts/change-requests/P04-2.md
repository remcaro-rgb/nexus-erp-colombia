# CCR P04-2 — contract additions for F-PORTAL-CORE / P04 (integrator, `contracts/src`)

* From: P04 · To: integrator (P02 sources `contracts/src/**`, `contracts/errors.yaml`) · Type: additive · Status: OPEN
1. **`POST /api/portal/v1/invitations:accept`** (portal fragment, `x-owner: P04`, `x-features: [F-PORTAL-CORE]`,
   `security: oauth2 [portal]`, `Idempotency-Key` required). Body `{token: string (maxLength 200)}`; 200 →
   `{external_account_id: uuid, external_status: "ACTIVE"}`; errors `unauthenticated` (401, token not from `erp-portal`
   or subject already linked), `not_found` (404, unknown/superseded invitation), `invitation_expired` (410),
   `invalid_state_transition` (409, already used). It links the Keycloak subject that just set its password to the invited
   account (INVITED → ACTIVE). Implemented in `backend/iam/external/views.py::PortalAcceptInvitationView`; today it is an
   `undocumented_operation` for `contracts/tools/drift.py`.
2. **Error code `filter_not_allowed`** (400, module iam): filter, sort or search over a field the principal cannot read
   (or reads masked) — named by the P04 prompt ("filters on unreadable fields are rejected (`400 filter_not_allowed`)").
3. **Error codes `BRANCH_ARCHIVED` / `BRANCH_COMPANY_MISMATCH`** (422) named by FEATURES-ADDENDUM F-ACC-BRANCH › Posting,
   raised by `iam.branches.services.assert_postable_branch` / `validate_branch_link` (lower-case aliases are fine; tell P04).
4. `ExternalAccount.last_login_at` (date-time, readOnly, internal) — the F-PORTAL-CORE UI shows "last login"; returned by the API.
5. `CostCenterScope`: add `node_type` and `parent_id` (readOnly) and the query parameter `view=tree` on
   `GET /api/v1/iam/cost-centers` (T-ACC-DIM-09 "tree"); both are returned/accepted today.
