# CCR P13b-1 — publish the HR interface payroll consumes (`kernel.interfaces`)

* From: P13b · To: P13a (HR provider) / integrator (kernel.interfaces owner) · Type: additive interface · Status: OPEN
* Why: payroll needs employees with their payroll contract data per period. `backend/kernel/**` is not a P13b path,
  so the consumer-side Protocol lives in `backend/payroll/interfaces.py` and payroll resolves it from
  `kernel.services` (fails closed with `service_unavailable` when nobody registered it). Tests use
  `payroll.testing.fakes.FakeEmployeeSource` (fake allowed until G2).
* Requested:
  1. Move (or re-export) `PayrollEmployee` and `PayrollEmployeeSource` from `payroll.interfaces` to
     `kernel.interfaces.hr` with exactly this shape (frozen for P13b):
     ```python
     @dataclass(frozen=True, slots=True)
     class PayrollEmployee:
         employee_id: UUID; company_id: UUID; full_name: str; contract_id: UUID
         contract_type: str            # INDEFINIDO | FIJO | OBRA_LABOR | APRENDIZAJE (prestación de servicios is not payroll)
         salary: Decimal               # monthly contract salary, COP
         salary_type: str = "ORDINARIO"  # ORDINARIO | INTEGRAL
         start_date: date | None = None; end_date: date | None = None
         arl_risk_class: str = "I"; cost_center_id: UUID | None = None; exonerated: bool = False
         days_worked: Decimal | None = None          # None → derived by payroll (30-day convention)
         hours: dict[str, Decimal] = {}              # approved timekeeping hours by type (e.g. "overtime_day")

     class PayrollEmployeeSource(Protocol):
         def employees_for_period(self, company_id, start, end, employee_ids=None) -> list[PayrollEmployee]: ...
     ```
  2. P13a registers its implementation at app ready: `services.register(PayrollEmployeeSource, impl)` (only when no
     implementation is registered, so tests keep their fakes).
* After the move, P13b (or the integrator) changes one import line in `backend/payroll/interfaces.py` to re-export.
