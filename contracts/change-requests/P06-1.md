# CCR P06-1 — install the tax and localization apps and their routes

* From: P06 · To: P01 (settings / root URLconf owner) and the integrator · Status: OPEN · Blocking: no (tests use a bridge)
* Files outside P06's paths: `backend/erp/settings/base.py`, `backend/erp/urls.py`.

Requested change:
1. `INSTALLED_APPS += ["localization_co", "tax"]` (order: after `"kernel"`; `localization_co` before `tax`).
2. In `backend/erp/urls.py`: `path("api/v1/tax/", include("tax.urls"))`.

Why: P06 delivers Django apps with models/migrations (`tax_*`, `localization_co_*` tables) and the API of
`contracts/openapi/modules/tax.yaml`. Until the apps are installed, `manage.py migrate` ignores them and the routes are
not served.

Bridge used meanwhile (remove nothing when applying the CCR): the P06 test conftests call
`tax.testing.bootstrap.ensure_installed()`, which adds the two apps to the app registry before the test database is
created (no-op once the settings list them), and API tests use `tax.testing.urls` (root URLs + tax routes).
`make migrations-check` does not see the P06 apps until this CCR is applied; P06 verified `makemigrations --check`
with the apps installed (no pending changes).
