# CCR P13b-2 — payroll contract: document the explain / legal-label fields of the responses

* From: P13b · To: P02 (contracts/src owner) / integrator · Type: additive (response fields) · Status: OPEN
* Why: F-PAY-FORMULA requires the explain trace per payslip line and the label NOT LEGALLY VERIFIED in the payslip
  (T-PAY-FORMULA-03). `contracts/src/modules/payroll.yaml` is not a P13b path and the generated
  `contracts/openapi/modules/payroll.yaml` must not be hand-edited (drift check), so the implementation returns these
  additional, read-only properties today. Please add them to the source and regenerate:
  * `Payslip` (readonly): `status` (CALCULATED|POSTED), `employee_name` (restricted-pii), `employer_cost`
    (money confidential), `lines` (array, confidential: concept, concept_type, sequence, amount, quantity,
    formula_id, formula_version, formula_hash, inputs, trace[{expr,value,pos}], parameters[], electronic_payroll_code),
    `legally_verified` (bool), `legal_notice` (string, "NOT LEGALLY VERIFIED" or ""), `parameters` (array of parameter
    snapshots: code, input, value, status, source_id, valid_from, valid_to, legally_verified, label), `masked` (array of
    field names hidden by the field policy).
  * `PayrollRun`: `number`, `status` (DRAFT|CALCULATED|APPROVED|POSTED|PAID), `calculation_date`, `graph_order`,
    `legally_verified`, `legal_notice`, `parameter_snapshot`, `warnings`, `totals` {earnings, deductions, net_pay,
    employer} (money confidential), `journal_entry_id`.
  * `PayrollPeriod` input: optional `code`, `name`. `ElectronicPayroll`: `document_type`, `adjustment_kind`, `replaces`,
    `transmission_status`, `label`, `documents` (count).
  * `concepts:validate-graph` `ActionRequest.parameters.on` (date, default business date) and `ActionResult.data`
    {on, order[], errors[], parameters[]} with `status` `valid|invalid`.
  * `runs/{id}:pay` `ActionRequest.parameters.payment_ref`; `electronic-payroll/{id}:adjust`
    `ActionRequest.parameters.kind` (Reemplazar|Eliminar).
* No route is added: every implemented route is already in the frozen contract (tests/security route conformance).
