# CCR P05-4 — ledger API notes against the frozen contract (P02)

* From: P05 · To: P02 / integrator · Type: clarification · Status: OPEN
1. `POST /dimensions/{dim}/{id}:move` (body `ActionRequest`): the new parent travels as `parameters.parent_id`
   (`null` = root). Please document it in the operation description.
2. Validation errors of the hierarchy that have no dedicated code use `validation_failed` with
   `errors.pointer = /parent_id` and `errors.reason` ∈ {`parent_not_agrupador`, `parent_other_dimension`};
   a parent of another company (or unknown) is `dimension_cross_company` (no existence oracle).
3. `POST /entries` is implemented as "create and post a manual entry" in one UoW (`ledger.entry.post`) with body
   `{posting_date, journal_code, purpose, lines[{account, debit|credit, currency, fx_rate, dimensions{…}}]}`;
   `POST /journal-entries:simulate` takes the same body in `parameters`. Draft entries (`:post` on a draft) are not
   in this attempt.
4. `:import` (multipart, 202) is P18's import pipeline; not served by P05 in this attempt (no fake endpoint).
5. Posting into a SOFT_CLOSED period is allowed only to principals with `ledger.period.update` (the closing team).
   Please add a dedicated code `ledger.period.post_soft_closed` to the catalog sources (`contracts/src`); the catalog is
   generated, so P05 did not edit it. P05 switches to the new code once it exists.
