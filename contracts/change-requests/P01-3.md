# CCR P01-3 — kernel event schemas

* From: P01 · To: P02 · Type: additive (`contracts/events/kernel/`) · Status: OPEN
* Kernel emits these events through the outbox (envelope per shared/02 §2, produced by `kernel.events.DomainEvent.envelope()`):
  * `kernel.sequence.threshold.v1` — payload `{sequence_id: uuid, sequence_code: string, prefix: string,
    threshold: "0.80"|"0.95" (decimal string), number: integer, range_to: integer}`; company-scoped.
  * `kernel.sequence.exhausted.v1` — payload `{sequence_id, sequence_code, prefix}`. Note: emitted inside the failing
    UoW, so it rolls back with it; consumers needing a durable alert should rely on the threshold events (95 %).
* Envelope details to confirm in the envelope schema: `schema_version` is the integer N of `.vN`; `actor.type` ∈
  {user, service, ai_agent, mcp_client}; Decimals are JSON strings, never numbers.
