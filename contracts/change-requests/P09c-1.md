# CCR P09c-1 — recipes/BOM and transformations: wiring, contract additions and ledger roles (non-breaking)

Owners of the change: P09a (`frontend/src/features/inventory/module.ts`), P02 (`contracts/src/modules/inventory.yaml`),
P05/P21 (standard ledger roles and synthetic PUC seed), integrator (migration graph).
Status: PROPOSED. P09c implements everything below inside its own paths; nothing in another task's path was edited.

1. **UI wiring (P09a).** The shell discovers only `features/*/module.ts`. P09c exports its pages from its own folders:
   `bomPages` (`features/inventory/bom/index.ts`: `produccion/recetas`) and `transformationPages`
   (`features/inventory/transformations/index.ts`: `produccion/transformaciones`, `produccion/plantillas-porcionado`).
   Proposed: `module.ts` spreads both into `pages` (`pages: { ...corePages, ...bomPages, ...transformationPages }`).
   Until then the registry tabs of submenu `produccion` show the shell's honest "Módulo aún no disponible" state.
2. **Transformation type `PRODUCTION` (additive).** Besides PRESENTATION / PORTIONING / MANUAL the engine supports
   PRODUCTION orders from an ACTIVE BOM (`bom_id`, `planned_qty`; lines exploded single-level when none are sent,
   byproducts receive their `cost_share_percent`, the main output the rest). Proposed: add the enum value and both fields
   to `TransformationInput`/`Transformation`.
3. **Additional fields (additive).** Order: `inputs_reserved`, `approval_required`, `approval_reasons[]`, `approval_note`,
   `approved_by`, `approved_at`, `tolerance_percent`, `value_in`, `value_out`, `waste_expensed`, `journal_entry_id`,
   `reversal_entry_id`, `posted_at`, `reversed_at`. Line: `qty_packages`, `actual_weight`, `cost_share`, `is_main`,
   `is_byproduct`, `abnormal`, `lot_code`, `unit_cost`, `value`. Cost/value fields are `confidential`.
4. **Actions (additive).** `transformations/{id}:reject` (permission `inventory.transformation.approve`) and
   `transformations/{id}:cancel` (`inventory.transformation.update`, releases reservations). `:simulate` answers the
   plan (`inventory.transformation.read`, costs stripped when hidden by the field policy).
5. **Permission `inventory.transformation_manual.create`** (appended to `contracts/permissions/catalog.yaml`,
   source P09c). The grammar has no `manual` verb, so the extra gate for free multi-item documents is a resource code;
   no default role grants it. Proposed: P02/P03 add it to the inventory admin role of the seed.
6. **Ledger roles.** The engine posts through `AccountDetermination` roles: `INVENTORY` (or `INVENTORY_<CATEGORY>` when
   that role is mapped, e.g. `INVENTORY_CARNICOS`), `SCRAP_EXPENSE` (abnormal waste), `TRANSFORMATION_COST_CLEARING`
   (additional costs capitalized into outputs), `INVENTORY_ADJ_GAIN` / `INVENTORY_ADJ_LOSS` (average-cost variance on
   reversal). A missing role fails the whole document with `account_determination_missing`. Proposed: P05/P21 add them
   to the standard role list and to the synthetic PUC seed (labelled SINTÉTICO).
7. **Migration graph.** P09c ships `inventory/bom/migrations/0121_p09c_bom_transformations.py` and
   `inventory/transformations/migrations/0122_p09c_db_guards.py`, both rooted on `inventory.0002_db_guards`. If P09b
   also roots on 0002, the integrator adds a merge migration (no schema overlap: different tables).
