# CCR P22b-4 / DEF-P22-008 — `kernel.parameters.enforce` overwrites the error code (P01)

* From: P22b · To: P01 (kernel) · Status: OPEN · Defect: DEF-P22-008
  (strict xfail `tests/cross_module/scenarios/test_S06_S07_payroll_timekeeping.py::test_p22b_S07_t76_unknown_parameter_keeps_its_error_code`).
* Observed: `enforce()` raises `ParameterUnknown(f"parameter {code} …", code=code)` and `ParameterNotVerified(…, code=code)`.
  `DomainError.__init__(code=…)` *replaces* the error code, so `exc.code == "smmlv.2027"` and the problem+json `type` is
  `…/smmlv.2027` instead of `…/parameter_unknown`. Fail-closed handling that matches on the code (C1-9, T7-6 "blocked if 2027
  SMMLV is UNKNOWN") cannot recognise it; P06 is unaffected only because it wraps the error in `TaxParameterUnknown`.
* Request: pass the parameter as extra data (`parameter=code`), not as `code=`, in both raises.
