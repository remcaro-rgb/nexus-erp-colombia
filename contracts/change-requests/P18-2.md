# P18-2 — owner service for exógena concept mappings (to P17 / P06)

Status: OPEN (P18, wave 06).

`contracts/dataio/exogena-mappings.yaml` assigns the template to module `reporting` (owner P17) with natural key
`(pack_code, concept)` and permission `reporting.exogena_mapping.update`. No model or service for concept mappings
exists on `main` (the only concept data is the `concepts` list inside a format pack, `tax.exogena`).

dataio never writes another module's tables directly, so the `exogena-mappings` template is **not registered** until
an owner service exists. Request: provide `create_mapping(uow, company_id, data)` / `update_mapping(uow, row, data)`
(+ model with the natural key above). The P18 adapter is ~60 lines on the pattern of `dataio/templates/tax.py`.
The format-pack template (`exogena-format-packs`) is delivered and tested.
