# CCR P09b-2 — seed data and migration ordering for F-INV-ISSUE (to P07 / P21 seed / integrator)

Status: OPEN (P09b, wave 04).

1. **Workflow policy** (P07): stock issues request approval with policy code `inventory.stock_issue`
   (`inventory.issues.service.APPROVAL_POLICY`). The DB-backed `WorkflowService` needs a seeded policy with this code
   (single step, approver ≠ requester per D-023). Tests use `FakeWorkflowService`, which enforces the same SoD rule.
2. **Account determination** (P21 dev seed): the seeded concepts post to roles `INVENTORY_CONSUMPTION_EXPENSE`,
   `INVENTORY_DIRECT_CONSUMPTION`, `INVENTORY_SCRAP_EXPENSE`, `INVENTORY_SAMPLES_EXPENSE`,
   `INVENTORY_OTHER_ISSUE_EXPENSE` (credit side `INVENTORY`). The demo seed should map them to synthetic PUC accounts and
   call `inventory.issues.service.seed_concepts(uow, company_id)` per company.
3. **Migration leaf** (integrator): P09b adds `inventory/issues/migrations/0101_p09b_issues_barcodes.py`
   (depends on `inventory.0002_db_guards`, `iam.0002_security`). If P09c also adds a migration on top of `0002`,
   `makemigrations --merge` (an empty merge migration) is needed when both land.
