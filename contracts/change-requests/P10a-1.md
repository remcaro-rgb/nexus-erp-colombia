# CCR P10a-1 — additive fields and routes of the sales / CRM contract

* From: P10a · To: contracts owner (integrator) · Type: additive (no field removed or retyped) · Status: OPEN
* Why: the generated `contracts/openapi/modules/sales.yaml` / `crm.yaml` use the generic document schema
  (`status` enum DRAFT…CANCELLED, `additionalProperties: false`). F-SAL-PRICING (D-024) needs the price snapshot and the
  reprice diff on documents, and the sales cycle has more states than the generic enum. The implementation keeps the
  contract `status` enum and ADDS the fields below; validators that enforce `additionalProperties: false` on responses
  need these properties added to `contracts/src/modules/{sales,crm}.yaml` and the module regenerated.

## Sales (`contracts/src/modules/sales.yaml`)
1. Documents (quotes, orders, invoices, notes): `document_status` (string, internal, ro — detailed state: quotes
   DRAFT/SENT/ACCEPTED/ORDERED/CANCELLED; orders DRAFT/PENDING_APPROVAL/CONFIRMED/PARTIALLY_DELIVERED/DELIVERED/INVOICED/
   CANCELLED; invoices DRAFT/POSTED), `fiscal_status` (string, ro), `cufe` (string|null, ro), `reprice_diff` (array, ro),
   `cost_total` and `margin` (money, **confidential**), `branch_id`, `warehouse_id`, `deliver_on_invoice`, `due_date`,
   `journal_entry_id`, `order_id`.
   Mapping of `status`: SENT→SUBMITTED, ACCEPTED/ORDERED/CONFIRMED/PARTIALLY_DELIVERED/DELIVERED/INVOICED→APPROVED,
   PENDING_APPROVAL→SUBMITTED, POSTED→POSTED, CANCELLED→CANCELLED.
2. Lines: `price_source` (OVERRIDE|FORMULA|LIST|BASE), `override_status` (NONE|WITHIN_LIMIT|PENDING_APPROVAL|APPROVED|
   REJECTED), `price_snapshot` (object; `detail.inputs.cost` and `detail.trace` are **confidential**, resource
   `sales.price_snapshot`), `override_reason` (input), `delivered_qty`, `invoiced_qty`, `cost_value`, `components`, `margin`
   (**confidential**, resource `sales.line`).
3. Actions: `POST /quotes/{id}:reprice` and `POST /invoices/{id}:reprice` (ActionRequest `parameters.apply` boolean; without
   `apply` the call is a preview that persists nothing; a non-DRAFT invoice answers `pricing_posted_document_immutable`).
4. Routes: `GET|POST /item-prices` (item base price, the lowest D-024 level; permission `sales.price_list.read` /
   `sales.price_list.update`), `GET /parties/duplicates?nit=&email=&phone=` (permission `sales.party.read`).
5. `pricing:quote` (`ActionRequest.parameters`): `{party|customer|customer_id, items[{item_id, quantity, uom?,
   override_price?, discount_pct?}], date?, currency?, fx_rate?, channel?}` → `ActionResult.data = {date, currency,
   items[{item_id, quantity, unit_price, source, override_status, discount_pct, explain}]}`.
6. Party: `trade_name`, `dv`, `person_type`, `roles`, `einvoice_email`, `municipality_code`, `tax_profile_id`,
   `price_list_id`, `customer_group`, `salesperson_id`, `territory`, `consent_ref`, `merged_into`.

## CRM (`contracts/src/modules/crm.yaml`)
* Lead: `code`, `company_name`, `nit` (confidential), `campaign`, `score`, `consent_ref`, `party_id`, `opportunity_id`,
  `lost_reason`; `:convert` parameters `{consent_ref, nit?, dv?, person_type?, legal_name?, party_id?, opportunity?{…}}`.
* Contact: `code`, `consent_ref`. Opportunity: `code`, `opportunity_status` (OPEN|WON|LOST), `owner_id`, `lead_id`,
  `lost_reason`, `weighted_amount` (confidential). Activity: `owner_id`, `done`. Pipeline stage objects
  `{code, name, probability}`.
* `GET /forecast` returns `ReportResult` with `rows` by stage and `totals.{by_currency, by_owner}`; amounts need the
  confidential field grant of resource `crm.forecast` (else 403 `field_forbidden`).
