# CCR P11a-3 — download route for quote attachments (buyers only)

* From: P11a · To: P02 / integrator · Type: additive route · Status: OPEN

T-PUR-CYCLE-06 requires attachments to be "downloadable by buyers only". The frozen contract has only
`GET|POST /rfqs/{rfq_id}/quotes/{id}/attachments` (list / upload). P11a implements the download as the service
`purchasing.services.attachments.download(ctx, company, rfq_id, quote_id, attachment_id)` (permission
`purchasing.quote.read`, same company, SHA-256 integrity check; other tenants/companies → `not_found`) and does not
expose an undocumented route (UR-22). Requested:

`GET /api/v1/purchasing/rfqs/{rfq_id}/quotes/{id}/attachments/{attachment_id}/content` → `200 application/octet-stream`
(`Content-Disposition: attachment`), `x-permission: purchasing.quote.read`, errors `not_found`, `policy_denied`.
Once in the contract P11a/P11b adds the 10-line view calling that service.
