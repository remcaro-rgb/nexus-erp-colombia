# CCR P16b-3 — UI navigation permission `consolidation.read`

* From: P16b · To: P04 (IAM nav permissions) / integrator · Type: clarification · Status: OPEN

The registry submenu `tesoreria › intercompania` uses the module-level permission `consolidation.read` (not a
`<module>.<resource>.<action>` catalog code). The page itself only calls endpoints guarded by catalog codes
(`intercompany.reconciliation.read`, `intercompany.agreement.*`, `consolidation.group.*`, `consolidation.run.*`,
`consolidation.consolidation_report.read`). Request: make the IAM navigation layer derive `consolidation.read` from
any `consolidation.*.read` / `intercompany.*.read` grant (as it does for other module-level permissions), so the
contributed submenu is visible to the Contador role.
