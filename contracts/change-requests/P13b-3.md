# CCR P13b-3 — payroll account roles for in-line posting (ledger / seed)

* From: P13b · To: P05 (ledger roles) / P21 (synthetic PUC determinations) / integrator · Type: additive data · Status: OPEN
* Why: `payroll.runs.post` posts one balanced entry through `PostingService` (journal `PAYROLL`) with account roles;
  the real `LedgerPostingService` fails with `account_not_found` until the roles have determinations. P13b tests use the
  PostingService test double; `ledger/setup.py` is not a P13b path.
* Requested roles (codes are data; the PUC accounts come from the tenant / P21 synthetic seed, never invented here):
  `PAYROLL_EXPENSE` (default debit of DEVENGO), `PAYROLL_DEDUCTIONS_PAYABLE` (default credit of DEDUCCION),
  `PAYROLL_NET_PAYABLE` (net pay, party = employee), `PAYROLL_CONTRIBUTIONS_EXPENSE` / `PAYROLL_CONTRIBUTIONS_PAYABLE`
  (APORTE), `PAYROLL_PROVISIONS_EXPENSE` / `PAYROLL_PROVISIONS_LIABILITY` (PROVISION). A concept's own `account_role`
  overrides the default debit (DEVENGO/APORTE/PROVISION) or credit (DEDUCCION) role.
* Lines carry `dimensions.cost_center_id` from the employee contract, so the dimension rule matrix applies.
