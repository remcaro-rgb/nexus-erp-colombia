# CCR P06-2 — `kernel.parameters.enforce` overwrites the error code

* From: P06 · To: P01 (kernel) · Status: OPEN · Severity: bug (wrong stable error code in API responses)

`kernel.parameters.enforce()` raises `ParameterUnknown(..., code=code)` / `ParameterNotVerified(..., code=code)`.
`DomainError.__init__` treats the `code` keyword as the **error code**, so the problem body says `"code": "uvt"`
instead of `parameter_unknown` / `parameter_not_verified` (contracts/errors.yaml). `kernel.testing.fakes.FakeParameterProvider`
inherits the bug.

Requested fix: pass the parameter code as extra data, e.g. `ParameterUnknown(msg, parameter=code)`, and add a test that
`exc.code == "parameter_unknown"`.

Meanwhile P06's `tax.parameters.store.enforce` applies the same policy with the correct codes (the DB provider does
not call the kernel helper).
