# CCR P05-6 — `SecuredAPIView` / `SecuredViewSet` missing on main (P04, ADR-004)

* From: P05 (attempt 2) · To: P04 (owner of the secured DRF bases), P03 (static checks) · Type: interface · Status: OPEN
* The CI `policy` job (`scripts/ci/static_checks.py`, SEC-VIEW) requires every DRF view to inherit
  `SecuredViewSet`/`SecuredAPIView`, which ADR-004 places in `backend/iam/...` / `backend/kernel/api/...`. Neither class
  exists on `main`, so no module can comply: `main` already fails SEC-VIEW for `backend/tax/api/base.py` (TaxAPIView)
  and `backend/workflow/api.py` (WorkflowView); P05's `backend/ledger/api.py:LedgerAPIView` fails the same way.
* Request: P04 delivers `SecuredAPIView` (authentication + policy check + tenant binding + field security); then
  P05 changes `LedgerAPIView(APIView)` to `LedgerAPIView(SecuredAPIView)` (one-line change, P05 paths).
* P05 meanwhile: `LedgerAPIView` uses `IsAuthenticated` and every handler calls `PolicyService` (deny-by-default,
  fails closed when no policy service is registered); tested by the API deny-by-default tests.
* Raw SQL (RAW-SQL) in `backend/ledger/posting.py` was removed in attempt 2 (ORM upsert; period `FOR SHARE` via the
  migration-defined function `ledger_period_status_for_share`).
